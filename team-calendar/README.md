> เพราะแต่ละท่านลงข้อมูลเอง — คู่มือตั้งค่าและสคริปต์อยู่ในโฟลเดอร์ [`google-calendar/`](google-calendar/README.md)

> Android ต้องใช้คอมพิวเตอร์ตั้งค่า และ Google อัปเดตช้าราว 12–24 ชม.) ชื่อและตารางในไฟล์ `schedule.json` เป็นข้อมูลสมมติ

## (พักไว้) แบบสมัครรับไฟล์ .ics

ปฏิทินกลางของอาจารย์ในสาย — งานประจำวัน (OR · OPD · ราวด์ · เวร) **วันลา** และ **การไปประชุม/อบรม** —
ที่เข้าไปอยู่ใน **แอปปฏิทินของเครื่องแต่ละคน** (Apple Calendar / Google Calendar) และอัปเดตตามเองเมื่อแก้ที่ต้นฉบับ

- **แยกสีตามคน** — อาจารย์แต่ละท่านมีปฏิทินของตัวเองหนึ่งอัน สีประจำตัว · มีปฏิทินรวมที่ใส่จุดสีของคนหน้าชื่องาน (🔵 OR)
- **เตือนงานชนกัน** — เช่น ลาหรือไปประชุมแต่ยังมี OPD/OR ค้างอยู่ในตาราง

## ขอบเขตตอนนี้

| | |
|---|---|
| ใครอยู่ในปฏิทิน | **เฉพาะอาจารย์สายฟ้า** (ยังไม่รวมแพทย์ประจำบ้าน/อินเทิร์น) |
| ความเกี่ยวข้องกับระบบอื่นของแผนก | **ไม่มี** — โฟลเดอร์นี้ทำงานเองทั้งหมด ไม่ใช้ไฟล์ รูป secret หรือข้อมูลจากระบบคิวห้องผ่าตัด แฟ้มสะสมงาน หรือบอท LINE เดิม |
| ที่อยู่ของโค้ด | branch แยก (`claude/awesome-rubin-46i7j9`) **ยังไม่รวมเข้า `main`** และไม่มีอะไรไปแก้ไฟล์ของระบบเดิม |
| แจ้งเตือน LINE | **ปิดไว้ก่อน** — โค้ดยังอยู่ (`notify.mjs`) แต่ไม่มีตารางเวลาส่งอัตโนมัติ |

```
schedule.json ──► build.mjs ──► feeds/*.ics ──► แอปปฏิทินในเครื่องแต่ละคน (สมัครรับ / subscribe)
                                           └─► index.html (หน้าดูรวม)
```

repository นี้เป็นสาธารณะ — ชื่ออาจารย์ ตารางงาน วันลา และการไปประชุม **เห็นได้โดยคนที่รู้ลิงก์**

- **ห้ามใส่ชื่อผู้ป่วย HN การวินิจฉัย หรือข้อมูลผู้ป่วยใด ๆ** — ใช้แค่ "OR ห้อง 5"
- วันลาใส่แค่ "ลา" ก็พอ ไม่ต้องระบุเหตุผล
- ถ้าไม่ต้องการให้เป็นสาธารณะ ต้องใช้ปฏิทินที่แชร์เฉพาะบัญชีที่เชิญแทน (เช่น Google Calendar ที่แชร์กันในกลุ่มอาจารย์)

## ลิงก์สมัครรับ (ระหว่างทดสอบ)

ไฟล์ปฏิทินอ่านได้จาก branch นี้โดยตรง ไม่ต้องรวมเข้า `main`:

```
https://raw.githubusercontent.com/oomkhomgt-pixel/MNRH/claude/awesome-rubin-46i7j9/team-calendar/feeds/ortho-blue.ics           ← ปฏิทินรวม
https://raw.githubusercontent.com/oomkhomgt-pixel/MNRH/claude/awesome-rubin-46i7j9/team-calendar/feeds/ortho-blue-staff-a.ics   ← ของแต่ละท่าน
```

| | วิธีเพิ่ม |
|---|---|
| **iPhone** | ตั้งค่า → ปฏิทิน → บัญชี → เพิ่มบัญชี → อื่นๆ → **เพิ่มปฏิทินที่สมัครรับ** → วางลิงก์ |
| **Mac** | Calendar → File → New Calendar Subscription → วางลิงก์ |
| **Google Calendar** | **บนคอมพิวเตอร์** → "ปฏิทินอื่นๆ +" → "จาก URL" → วางลิงก์ (แอปมือถือเพิ่มจากลิงก์ไม่ได้ แต่เพิ่มแล้วจะขึ้นในมือถือเอง) |

ข้อจำกัดของการสมัครรับ (เป็นของ Apple/Google เอง):

- เป็นแบบ **อ่านอย่างเดียว** — แก้งานต้องแก้ที่ต้นฉบับ (`schedule.json`) ไม่ใช่ในแอปปฏิทิน
- **Google ดึงใหม่ช้า (หลายชั่วโมงถึงราวหนึ่งวัน) และเร่งไม่ได้** · Apple ดึงใหม่เป็นระยะ โดยทั่วไปราวทุกชั่วโมง
- สีของแต่ละปฏิทินตั้งในแอปของแต่ละคน (Apple รับสีที่กำหนดมาให้ตอนสมัคร ส่วน Google ต้องเลือกสีเองครั้งเดียว)

## แก้ตาราง

แก้ไฟล์ **`team-calendar/schedule.json`** — บนหน้าเว็บ GitHub เลือก branch นี้ กดรูปดินสอ ✏️ แก้ แล้ว Commit
ระบบจะตรวจไฟล์และสร้างปฏิทินใหม่ให้เองภายใน ~1 นาที ถ้าพิมพ์ผิดจะขึ้น ❌ พร้อมบอกจุดที่ผิดเป็นภาษาไทย (ปฏิทินเดิมยังอยู่ ไม่พังตาม)

### อาจารย์ — `members`

```json
{ "id": "staff-a", "name": "อ.นพ. สมชาย ใจดี", "short": "อ.สมชาย", "role": "Staff", "color": "blue" }
```

`id` ใช้เป็นชื่อไฟล์ปฏิทินของท่านนั้น — **อย่าเปลี่ยนหลังมีคนสมัครรับแล้ว** ลิงก์จะเปลี่ยน ·
สีที่เลือกได้: `red` `orange` `yellow` `green` `blue` `purple` `brown` `black` `pink` `teal` `grey`

### งานประจำ — `recurring`

```json
{ "id": "or-a", "type": "or", "title": "OR (ห้อง 5)", "who": ["staff-a"],
  "weekly": ["MO", "TH"], "start": "08:30", "end": "16:30", "location": "ห้องผ่าตัด 5",
  "from": "2026-11-02", "until": "2027-03-31", "cancel": ["2026-11-26"] }
```

- `weekly`: `MO TU WE TH FR SA SU` · `"every": 2` = สัปดาห์เว้นสัปดาห์
- รายเดือน: `"monthly": { "nth": -1, "day": "FR" }` = ศุกร์สุดท้ายของเดือน (`nth` 1–4 หรือ -1)
- `who: ["all"]` = อาจารย์ทุกท่าน
- `cancel` = งดเฉพาะวัน (เช่นวันที่ลา) · **วันหยุดใน `holidays` งดให้อัตโนมัติ**

### วันลา · ไปประชุม · เวร · งานครั้งเดียว — `events`

```json
{ "type": "leave", "title": "ลาพักร้อน", "who": ["staff-b"], "date": "2026-12-14", "end_date": "2026-12-18", "all_day": true }
{ "type": "conf",  "title": "ประชุมวิชาการ RCOST", "who": ["staff-a"], "date": "2026-11-25", "end_date": "2026-11-27", "all_day": true, "location": "กรุงเทพฯ" }
{ "type": "call",  "title": "Staff on call", "who": ["staff-c"], "date": "2026-11-19", "all_day": true }
{ "type": "or",    "title": "OR เพิ่ม (ห้อง 3)", "who": ["staff-b"], "date": "2026-11-24", "start": "13:00", "end": "17:00" }
```

- หลายวันใช้ `all_day` + `end_date` · `end` น้อยกว่า `start` = ข้ามคืน
- `leave` และ `conf` แบบทั้งวันนับว่า "ไม่อยู่" — ถ้ายังมีชื่อใน OR/OPD วันนั้น ระบบจะเตือนว่างานชน (ให้ใส่วันนั้นใน `cancel` ของงานประจำ หรือเปลี่ยนคน)

### วันหยุด — `holidays`

ไฟล์ตัวอย่างใส่ไว้เฉพาะ ธ.ค. 2569 – ม.ค. 2570 — **ตรวจกับประกาศ ครม. และเพิ่มให้ครบทั้งปี** (รวมวันหยุดชดเชย)

## สำหรับผู้พัฒนา

ไม่มี dependency — ใช้ Node 20+ เปล่า ๆ ทุกอย่างอยู่ในโฟลเดอร์นี้

```bash
node team-calendar/build.mjs                 # ตรวจ schedule.json + สร้าง feeds/*.ics
node team-calendar/build.mjs --check         # ตรวจว่า feeds/ ไม่ค้าง (ไม่เขียนไฟล์)
node --test team-calendar/test.mjs           # ชุดทดสอบ
python3 -m http.server -d . 8000             # แล้วเปิด http://localhost:8000/team-calendar/ เพื่อดูหน้ารวม
```

| ไฟล์ | หน้าที่ |
|---|---|
| `schedule.json` | ต้นฉบับเดียวของตาราง |
| `lib.mjs` | ตรวจไฟล์ · ขยายงานซ้ำเป็นรายวัน · ตรวจงานชน · วันที่ไทย |
| `ics.mjs` | เขียน iCalendar (RRULE/EXDATE, VTIMEZONE Asia/Bangkok, พับบรรทัดไม่ตัดสระไทย) |
| `build.mjs` | สร้าง `feeds/ortho-blue.ics` และ `feeds/ortho-blue-<id>.ics` |
| `index.html` | หน้าดูรวม: รายการ 14 วัน / เดือน · กรองรายคน |
| `notify.mjs` | ข้อความ LINE — **ปิดไว้ก่อน** (สั่งทดสอบเองได้จากหน้า Actions แบบ dry-run) |
| `feeds/` | **ไฟล์ที่สร้างอัตโนมัติ — อย่าแก้มือ** |

`.github/workflows/team-calendar.yml` ทำงานเฉพาะเมื่อไฟล์ในโฟลเดอร์นี้เปลี่ยน และใช้ secret ชื่อของตัวเอง
(`TEAM_LINE_*`) ไม่ร่วมกับ workflow อื่น
