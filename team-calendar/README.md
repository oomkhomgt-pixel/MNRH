# ปฏิทินทีมออร์โธปิดิกส์ (ทีมฟ้า) — Apple / Google Calendar + แจ้งเตือน LINE

ปฏิทินงานของทีม (OR · OPD · ราวด์ · เวร · conference · ลา) ที่

- **สมัครรับใน Apple Calendar และ Google Calendar ได้** — แก้ตารางที่เดียว ทุกคนเห็นในมือถือตัวเอง
- **แยกสีตามคน** — แต่ละคนมีปฏิทินของตัวเองหนึ่งอัน สีประจำตัว · ปฏิทินรวมมีจุดสีของคนหน้าชื่องาน (🔵🔴🟢 OR)
- **แจ้งเตือนเข้ากลุ่ม LINE ของทีม** วันละสองรอบ แยกเป็นรายคนพร้อมสี และ @แท็กชื่อแต่ละคนได้
- **เตือนงานชนกัน** — คนที่ลา/ไปประชุมแต่ยังมีชื่อในตาราง OR/OPD หรือมีงานเวลาซ้อนกัน

**หน้าเว็บของทีม:** https://oomkhomgt-pixel.github.io/MNRH/team-calendar/ (ใช้ได้หลังรวมเข้า `main`)

```
schedule.json ──► build.mjs ──► feeds/*.ics ──► Apple / Google Calendar (สมัครรับ)
      │                                     └─► index.html (หน้าเว็บของทีม)
      └────────► notify.mjs ──► กลุ่ม LINE (06:45 งานวันนี้ · 18:45 งานพรุ่งนี้)
```

## แก้ตาราง (ผู้ประสานงานทีม)

แก้ไฟล์ **`team-calendar/schedule.json`** ไฟล์เดียว — บนหน้าเว็บ GitHub กดรูปดินสอ ✏️ แก้ แล้ว Commit
GitHub Actions จะตรวจไฟล์และสร้างปฏิทินใหม่ให้ภายใน ~1 นาที ถ้าพิมพ์ผิด Actions จะขึ้น ❌ พร้อมบอกบรรทัดและวิธีแก้เป็นภาษาไทย
(ปฏิทินเดิมยังอยู่ ไม่พังตาม)

### สมาชิก — `members`

```json
{ "id": "r2", "name": "นพ. สมชาย ใจดี", "short": "R2 ชาย", "role": "R2", "color": "green" }
```

| ช่อง | ความหมาย |
|---|---|
| `id` | รหัสสั้น a-z 0-9 - (ใช้เป็นชื่อไฟล์ปฏิทินของคนนั้น — **อย่าเปลี่ยนหลังทีมสมัครรับแล้ว** ลิงก์จะเปลี่ยน) |
| `name` / `short` | ชื่อเต็ม / ชื่อสั้นที่แสดงในปฏิทินรวมและหน้าเว็บ |
| `color` | `red` `orange` `yellow` `green` `blue` `purple` `brown` `black` `pink` `teal` `grey` |

เปลี่ยนรอบหมุนเวียน (resident ย้ายสาย): **เก็บ `id` เดิมตามตำแหน่ง** (เช่น `r2`) แล้วเปลี่ยนแค่ `name` —
คนใหม่สมัครรับลิงก์เดิมของตำแหน่งได้เลย ไม่ต้องแจกลิงก์ใหม่ทุกเดือน

### งานประจำ — `recurring`

```json
{ "id": "or-mon-thu", "type": "or", "title": "OR ทีมฟ้า (ห้อง 5)", "who": ["staff-a", "r4", "r2"],
  "weekly": ["MO", "TH"], "start": "08:30", "end": "16:30", "location": "ห้องผ่าตัด 5",
  "from": "2026-11-02", "until": "2027-03-31", "cancel": ["2026-12-24"] }
```

- `weekly`: `MO TU WE TH FR SA SU` · เพิ่ม `"every": 2` = สัปดาห์เว้นสัปดาห์
- รายเดือน: `"monthly": { "nth": -1, "day": "FR" }` = ศุกร์สุดท้ายของเดือน (`nth` 1–4 หรือ -1)
- `who: ["all"]` = ทั้งทีม (คนที่ลาวันนั้นจะถูกตัดออกในหน้าเว็บและ LINE ให้เอง)
- `cancel` = งดเฉพาะวัน · **วันหยุดใน `holidays` งดให้อัตโนมัติ** (ปิดได้ต่องานด้วย `"skip_holidays": false`)
- `remind_min` = แจ้งเตือนในปฏิทินก่อนกี่นาที (ตั้งค่าเริ่มต้นต่อประเภทได้ใน `task_types`)

### งานครั้งเดียว — `events`

```json
{ "type": "call", "title": "เวรนอก (ER)", "who": ["r2"], "date": "2026-11-20", "start": "16:00", "end": "08:00" }
{ "type": "leave", "title": "ลาพักร้อน", "who": ["r3"], "date": "2026-12-14", "end_date": "2026-12-18", "all_day": true }
```

- `end` น้อยกว่า `start` = ข้ามคืน (เวร 16:00–08:00 จบเช้าวันถัดไป)
- ลา/ไปประชุมหลายวัน ใช้ `all_day` + `end_date` · ประเภท `leave` และ `conf` แบบทั้งวันถือว่า "ไม่อยู่" ใช้ตรวจงานชน
- แลกเวร/เปลี่ยนคนเฉพาะวัน: ใส่วันนั้นใน `cancel` ของงานประจำ แล้วเพิ่มเป็นงานครั้งเดียวด้วยคนใหม่

### วันหยุด — `holidays`

วันหยุดราชการในไฟล์ตัวอย่างใส่ไว้เฉพาะ ธ.ค. 2569 – ม.ค. 2570 **ตรวจกับประกาศ ครม. และเพิ่มวันหยุดของปีให้ครบ**
(มาฆบูชา สงกรานต์ ฯลฯ รวมวันหยุดชดเชย)

## สมัครรับปฏิทิน (สมาชิกทีม)

เปิดหน้าเว็บของทีม → หัวข้อ "เพิ่มลงปฏิทินในมือถือ" → กดปุ่มในแถวของตัวเอง

| | วิธี |
|---|---|
| **iPhone / Mac** | ปุ่ม **Apple** → Subscribe · อยากได้การแจ้งเตือนก่อนงาน ให้ปิด "Remove Alerts" ตอนสมัคร |
| **Google Calendar** | ปุ่ม **Google** **บนคอมพิวเตอร์** (แอปมือถือเพิ่มจากลิงก์ไม่ได้) แล้วจะขึ้นในมือถือเอง |

ข้อจำกัดที่ต้องรู้ (เป็นข้อจำกัดของ Apple/Google ไม่ใช่ของระบบนี้):

- **Google ดึงปฏิทินที่สมัครรับใหม่ทุก 8–24 ชั่วโมง และเร่งไม่ได้** — งานที่เพิ่งแก้วันนี้ให้ดูใน LINE หรือหน้าเว็บ · Apple ประมาณทุก 1 ชั่วโมง
- ปฏิทินที่สมัครรับเป็น **อ่านอย่างเดียว** และ Google ใช้สีเดียวต่อปฏิทิน (สีกำหนดเองในแอป) —
  วิธีเห็นงานแยกสีตามคนในแอปเดียวคือ **สมัครรับปฏิทินของหลายคน** แต่ละอันคนละสี หรือใช้ปฏิทินรวมที่มีจุดสีหน้าชื่องาน

## ตั้งค่าแจ้งเตือน LINE (ครั้งเดียว ~15 นาที)

ใช้บอทตัวเดียวกับ `line-alert/` ได้ (บอทหนึ่งตัวอยู่ได้หลายกลุ่ม) — ถ้ายังไม่มีบอท ทำขั้นที่ 1 ใน
[`line-alert/README.md`](../line-alert/README.md) ก่อน

1. **เชิญบอทเข้ากลุ่ม LINE ของทีมฟ้า**
2. **หา Group ID** ของกลุ่มทีมฟ้า — วิธีเดียวกับขั้นที่ 3 ใน `line-alert/README.md` (ตั้ง webhook ชั่วคราวที่ webhook.site
   แล้วพิมพ์ mention บอทในกลุ่ม ดูค่า `source.groupId`)
3. **(ไม่บังคับ) หา LINE user ID ของแต่ละคน เพื่อ @แท็กชื่อ** — ระหว่างที่ webhook ชั่วคราวยังเปิดอยู่ ให้สมาชิกแต่ละคน
   พิมพ์ mention บอทในกลุ่มหนึ่งครั้ง จะเห็น `source.userId` ของแต่ละคน (ขึ้นต้นด้วย `U`) — คนที่ถูกแท็กได้แจ้งเตือนแม้ปิดเสียงกลุ่มไว้
   ปิด webhook กลับเมื่อเสร็จ
4. **GitHub → Settings → Secrets and variables → Actions → New repository secret**

   | ชื่อ | ค่า |
   |---|---|
   | `LINE_CHANNEL_ACCESS_TOKEN` | token ของบอท (ถ้าตั้งไว้แล้วสำหรับ `line-alert/` ไม่ต้องตั้งซ้ำ) |
   | `TEAM_LINE_GROUP_ID` | Group ID ของกลุ่มทีมฟ้า |
   | `TEAM_LINE_USER_IDS` | (ไม่บังคับ) `{"staff-a":"U1234…","r2":"Uabcd…"}` — key คือ `id` ใน `members` |

5. **ทดสอบ:** แท็บ Actions → "ปฏิทินทีมออร์โธ" → Run workflow → `dry_run: true` → ดูข้อความใน log
   แล้วรันอีกครั้งด้วย `dry_run: false` เพื่อส่งจริงหนึ่งข้อความ

หลังจากนั้นส่งเองทุกวัน **06:45** (งานวันนี้) และ **18:45** (งานพรุ่งนี้) — วันที่ไม่มีงานของใครเลยจะไม่ส่ง (กันกลุ่มรก)
ตัวอย่างข้อความ:

```
📅 วันนี้ · Ortho Blue
พฤหัสบดี 19 พฤศจิกายน 2569

👥 ทั้งทีม
  • 07:00–08:00 ราวด์วอร์ดเช้า · หอผู้ป่วยออร์โธปิดิกส์

🔵 @อ.หนึ่ง (Staff)
  • 08:30–16:30 OR ทีมฟ้า (ห้อง 5) · ห้องผ่าตัด 5

🟡 @R1 หก (R1)
  • 16:00–08:00 (+1) เวรนอก (ER) · ER

🏖 ไม่อยู่
  🟠 @R3 สี่ — ลาพักร้อน ถึง ศ. 18 ธ.ค.
```

## สำหรับผู้พัฒนา

ไม่มี dependency — ใช้ Node 20+ เปล่า ๆ

```bash
node team-calendar/build.mjs                 # ตรวจ schedule.json + สร้าง feeds/*.ics
node team-calendar/build.mjs --check         # ตรวจว่า feeds/ ไม่ค้าง (ไม่เขียนไฟล์)
node --test team-calendar/test.mjs           # ชุดทดสอบ
node team-calendar/notify.mjs --dry-run --date=2026-11-19 --mode=today
python3 -m http.server -d . 8000             # แล้วเปิด http://localhost:8000/team-calendar/
```

| ไฟล์ | หน้าที่ |
|---|---|
| `schedule.json` | ต้นฉบับเดียวของตาราง |
| `lib.mjs` | ตรวจไฟล์ · ขยายงานซ้ำเป็นรายวัน · ตรวจงานชน · วันที่ไทย — ใช้ร่วมกันทั้ง Node และหน้าเว็บ |
| `ics.mjs` | เขียน iCalendar (RRULE/EXDATE, พับบรรทัดตามไบต์และไม่ตัดสระไทย, VTIMEZONE Asia/Bangkok) |
| `build.mjs` | สร้าง `feeds/<team>.ics` และ `feeds/<team>-<member>.ics` |
| `notify.mjs` | จัดข้อความ LINE (textV2 + @แท็ก) และส่ง |
| `index.html` | หน้าเว็บของทีม: รายการ 14 วัน / เดือน · กรองรายคน · ปุ่มสมัครรับ |
| `feeds/` | **ไฟล์ที่สร้างอัตโนมัติ — อย่าแก้มือ** |

ไฟล์ `.ics` ตรวจกับตัวอ่านอิสระ (ical.js ของ Mozilla) แล้วว่าวันที่ที่แอปปฏิทินขยายจาก RRULE ตรงกับที่หน้าเว็บและ LINE คำนวณทุกวัน
