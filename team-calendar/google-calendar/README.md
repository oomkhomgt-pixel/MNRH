# ปฏิทินอาจารย์สายฟ้า — Google Calendar ที่แชร์กัน + แจ้งเตือน LINE

ทุกท่านเห็นงานของกันและกันใน **แอปปฏิทินของเครื่องตัวเอง** (iPhone และ Android) เพิ่ม/แก้ได้จากมือถือ
แยกสีตามคน และมีสรุปเข้ากลุ่ม LINE เช้า–เย็น

```
ปฏิทิน Google 6 อัน (เจ้าของ = เฮีย · แชร์ให้ทุกท่านแก้ได้)
   สายฟ้า – มานิตา · ศุภศักดิ์ · คงธัช · อดิศร · ชนกันต์ · ทุกคน
        │                                  └─► แอปปฏิทินในมือถือของแต่ละท่าน (ดู + แก้ได้ สองทาง)
        └─► สคริปต์ในบัญชี Google ของเจ้าของ (Code.gs) ─► กลุ่ม LINE เช้า "วันนี้" · เย็น "พรุ่งนี้"
```

ไม่เกี่ยวกับระบบอื่นของแผนก: ไม่มีเซิร์ฟเวอร์ ไม่ใช้ GitHub ตอนทำงานจริง ไม่ใช้บอท LINE ตัวเดิม — ทุกอย่างอยู่ในบัญชี Google และ LINE ของเจ้าของ

> **ห้ามใส่ชื่อผู้ป่วย HN หรือข้อมูลผู้ป่วยใด ๆ ในปฏิทิน** ใช้แค่ "OR" "OPD" "ลาพักร้อน" "ประชุม …"

## งานประจำที่สคริปต์ลงให้

| วัน | งาน | ใคร | ลงที่ปฏิทิน |
|---|---|---|---|
| จันทร์ | OPD 09:00–16:00 | ทุกท่าน | สายฟ้า – ทุกคน (รายการเดียว ไม่ซ้อน 5 ช่อง) |
| อังคาร | OR 08:00–16:00 | มานิตา, ศุภศักดิ์ | ของแต่ละท่าน |
| พุธ | ER 08:00–16:00 + OPD ปกส. 13:00–15:00 | วนสัปดาห์ละท่าน: มานิตา → ศุภศักดิ์ → คงธัช → อดิศร → ชนกันต์ เริ่ม พ. 25 พ.ย. 2569 | ของท่านที่ถึงเวร |
| พฤหัสบดี | OR 08:00–16:00 | ชนกันต์ | ของท่านนั้น |
| ศุกร์ | OR 08:00–16:00 | คงธัช, อดิศร | ของแต่ละท่าน |

- **วันหยุดราชการ งดทุกงานประจำ** — ดึงรายการวันหยุดจากปฏิทิน "วันหยุดในไทย" ของ Google (รวมวันหยุดชดเชยและวันหยุดพิเศษตามมติ ครม.) และตรวจใหม่เองทุกวันที่ 1
  - รายการของ Google **ไม่ตรงกับวันหยุดราชการทุกวัน**: มีวันแรงงาน (ราชการไม่หยุด) และไม่มีวันเข้าพรรษา — สคริปต์ตัด/เติมสองวันนี้ให้
    แต่ **วันหยุดชดเชยที่เลื่อนเพราะชนกัน** (เช่น ปี 2570 อาสาฬหบูชาตรงวันอาทิตย์ เข้าพรรษาวันจันทร์) สคริปต์ไม่เดา จะขึ้นคำเตือนใน log ให้เทียบกับประกาศ ครม. แล้วเติมที่ `extraHolidays`
- ลำดับเวรวันพุธ ผู้เริ่ม และ "วันหยุดงดทุกงานหรือเฉพาะ OPD" เป็นค่าที่ **ตั้งไว้ก่อน รอยืนยัน** — แก้ได้ในส่วน `CONFIG` บนสุดของ `Code.gs` ก่อนรันขั้นที่ 2
- วันลา ประชุม งานสอน: แต่ละท่านเติมเองในแอปปฏิทิน

สีเริ่มต้น: มานิตา 🔴 · ศุภศักดิ์ 🔵 · คงธัช 🟢 · อดิศร 🟠 · ชนกันต์ 🟣 · ทุกคน ⚫ (เปลี่ยนได้ ดูหัวข้อ "เปลี่ยนสี")

## ส่วน A — เจ้าของสร้างปฏิทิน (ครั้งเดียว ~10 นาที · ทำบนคอมพิวเตอร์)

1. เปิด <https://script.google.com> ด้วย Gmail ที่จะเป็นเจ้าของ → **New project** → ตั้งชื่อ "ปฏิทินสายฟ้า"
2. ลบโค้ดตัวอย่างออกให้หมด → คัดลอก [`Code.gs`](Code.gs) ทั้งไฟล์ไปวาง → กดบันทึก (💾)
3. *(ถ้าจะให้สคริปต์แชร์ปฏิทินให้ในขั้นที่ 7)* ในส่วน `CONFIG.people` ใส่ Gmail ของอีก 4 ท่านในช่อง `email: ''` — ของตัวเองไม่ต้องใส่ ·
   ถ้าต้องการให้ท่านหนึ่งเป็นสำรองของเจ้าของ ใส่ชื่อท่านนั้นที่ `deputy: ''`
4. แถบบนเลือกฟังก์ชัน **`step1_createCalendars`** → กด **Run**
   - ครั้งแรก Google จะขออนุญาต: *Review permissions* → เลือกบัญชี → หน้าจอ "Google hasn't verified this app" → **Advanced** → **Go to ปฏิทินสายฟ้า (unsafe)** → ติ๊กทุกช่อง → **Allow**
     (ขึ้นคำเตือนเพราะเป็นสคริปต์ที่เฮียสร้างเอง ไม่ได้ผ่านร้านแอปของ Google — สคริปต์ทำงานในบัญชีของเฮียเท่านั้น)
   - ดูผลที่แถบ *Execution log* ด้านล่าง ต้องขึ้น ✅ 6 บรรทัด
5. เลือก **`step2_createRoutine`** → Run — ลงงานประจำถึง 30 ก.ย. 2570 (เปลี่ยนได้ที่ `routineUntil`)
6. เลือก **`step3_syncHolidays`** → Run — ใน log จะแสดงรายการวันหยุดราชการ **ให้ตรวจด้วยตาว่าตรงกับของโรงพยาบาล**
   ถ้าไม่ตรง แก้ `extraHolidays` / `notHolidays` แล้วรันใหม่
7. แชร์ปฏิทินให้ทุกท่าน เลือกทางใดทางหนึ่ง
   - **ให้สคริปต์ทำ:** แถบซ้าย **Services ( + )** → *Google Calendar API* → **Add** → เลือก **`step4_shareCalendars`** → Run
   - **ทำเอง:** ที่ <https://calendar.google.com> ชี้ที่ปฏิทินแต่ละอัน → ⋮ → *Settings and sharing* → *Shared with* → *Add people* →
     ใส่ Gmail ทั้ง 4 ท่าน → สิทธิ์ **Make changes and see event details** → Send (ทำ 6 ปฏิทิน)
8. เปิด <https://calendar.google.com> ตรวจว่าเห็นปฏิทิน 6 อันและงานประจำถูกวัน ถูกคน

## ส่วน B — แต่ละท่าน (ครั้งเดียว ~3 นาที)

1. เปิดอีเมลจาก Google Calendar (ปฏิทินละ 1 ฉบับ รวม 6 ฉบับ — ถ้าไม่เจอดูในสแปม) → กดลิงก์ **Add this calendar** ทุกฉบับ
   โดยล็อกอิน Gmail **บัญชีเดียวกับที่ได้รับอีเมล**
2. ให้ปฏิทินขึ้นในมือถือ

   | เครื่อง | วิธี |
   |---|---|
   | **Android** | แอป Google Calendar → ☰ → ติ๊กปฏิทิน "สายฟ้า – …" ทั้ง 6 · ถ้าไม่เห็น: Settings → Show more → แตะชื่อปฏิทิน → เปิด Sync |
   | **iPhone (ง่ายสุด)** | ติดตั้งแอป **Google Calendar** แล้วล็อกอิน — เสร็จ |
   | **iPhone (แอปปฏิทินของเครื่อง)** | ① Settings → Apps → Calendar → Calendar Accounts → Add Account → Google → ล็อกอิน (เปิดเฉพาะ Calendars ก็ได้) ② เปิด Safari ไปที่ <https://calendar.google.com/calendar/syncselect> → ติ๊กปฏิทิน "สายฟ้า – …" ทั้ง 6 → Save ③ Calendar Accounts → Fetch New Data → เลือกทุก 15 นาที (ถ้าเลือก Automatically จะอัปเดตเฉพาะตอนชาร์จและต่อ Wi-Fi) |

3. ตั้งสีตามตารางข้างบน (Google เก็บสีแยกรายคน จึงต้องตั้งเองครั้งเดียว): ใน Google Calendar แตะ ⋮ ข้างชื่อปฏิทิน → เลือกสี
   — iPhone ที่ใช้แอปของเครื่องจะได้สีตามที่ตั้งใน Google

### วิธีลงรายการให้ทุกคนเห็นถูก

- **เลือกปฏิทิน "สายฟ้า – ชื่อของท่าน" ทุกครั้งที่สร้างรายการ** — ถ้าลงในปฏิทินส่วนตัวหรือ iCloud คนอื่นจะไม่เห็น
  (iPhone: ตั้งเป็น Default Calendar ได้ที่ Settings → Apps → Calendar → Default Calendar)
- **ลา:** ตั้งเป็น "ทั้งวัน" ชื่อขึ้นต้นด้วย "ลา" เช่น `ลาพักร้อน` — ข้อความ LINE จะขึ้นในหมวด "ไม่อยู่"
- **ไปประชุม/อบรมนอก รพ.:** "ทั้งวัน" และมีคำว่า `ประชุม` `อบรม` `สัมมนา` หรือ `ดูงาน` ในชื่อ
- **ประชุม/สอนที่มีเวลา** (เช่น 13:00–15:00): ลงเป็นรายการมีเวลาตามปกติ
- **งดงานประจำเฉพาะวัน:** ลบรายการของวันนั้น แล้วเลือก **This event** (อย่าเลือก All events — จะหายทั้งชุด)
- **เปลี่ยนงานประจำถาวร:** แก้รายการแล้วเลือก **This and following events**
- ทุกท่านแก้รายการของกันและกันได้ — ลบพลาดกู้ได้จาก *Settings → Trash* ของปฏิทินนั้น (ภายใน 30 วัน)

## ส่วน C — แจ้งเตือนเข้ากลุ่ม LINE (เจ้าของทำครั้งเดียว ~15 นาที)

**อ่านก่อน — โควตา:** บัญชี LINE ฟรีส่งได้ **300 ข้อความ/เดือน** และการส่งเข้ากลุ่มนับ **ตามจำนวนคนในกลุ่ม**
กลุ่ม 5 ท่าน = ครั้งละ 5 → ส่งได้ 60 ครั้ง/เดือน · เช้า+เย็นเฉพาะวันที่มีงาน ≈ 220 ข้อความ/เดือน **พอ**
แต่ถ้ากลุ่มมีคนมากกว่านี้ หรือมีงานทุกเสาร์–อาทิตย์ จะไม่พอ — สคริปต์เช็กโควตาก่อนส่งทุกครั้งและ **งดรอบเย็นก่อน** เพื่อเก็บไว้ให้รอบเช้า
การพิมพ์ถามบอท ("วันนี้") **ไม่นับโควตา**

**กลุ่มที่ใช้:** ควรเป็นกลุ่มของอาจารย์ 5 ท่านเท่านั้น และ **กลุ่มหนึ่งมีบัญชีทางการ (บอท) ได้ตัวเดียว** — ถ้ากลุ่มเดิมมีบอทอื่นอยู่ บอทนี้จะออกเองทันที ให้ตั้งกลุ่มใหม่

1. สร้างบัญชี LINE ทางการ (ฟรี) ที่ <https://entry.line.biz/form/entry/unverified> → ชื่อเช่น "ปฏิทินสายฟ้า"
2. เข้า [LINE Official Account Manager](https://manager.line.biz) → เลือกบัญชีนั้น → **Settings → Messaging API → Enable Messaging API** → สร้าง provider (ชื่ออะไรก็ได้)
3. ใน Manager ตั้งค่าต่อ
   - *Settings → Account settings* → เปิด **อนุญาตให้เข้าร่วมกลุ่ม** (Allow bot to join group chats) — ค่าเริ่มต้นปิดอยู่ ถ้าไม่เปิด บอทจะออกจากกลุ่มทันที
   - *Settings → Response settings* → ปิด Greeting message และ Auto-response · เปิด **Webhook**
4. เข้า [LINE Developers Console](https://developers.line.biz/console/) (ล็อกอินเดียวกัน) → provider → channel → แท็บ **Messaging API** →
   ล่างสุด **Channel access token (long-lived) → Issue** → คัดลอก *(นี่คือรหัสลับ ห้ามส่งให้ใคร ห้ามวางในแชต)*
5. กลับที่ Apps Script → ⚙️ **Project Settings** → ล่างสุด **Script properties → Add script property** → ชื่อ `LINE_TOKEN` ค่า = token ที่คัดลอก → Save
6. เลือก **`step5_prepareLine`** → Run — log จะบอกชื่อบอท และข้อความขึ้นต้น `?k=…` ให้คัดลอกไว้
7. มุมขวาบน **Deploy → New deployment** → ⚙️ เลือก **Web app** → *Execute as:* **Me** · *Who has access:* **Anyone** → Deploy → คัดลอก **Web app URL** (ลงท้าย `/exec`)
8. LINE Developers Console → แท็บ Messaging API → **Webhook URL** = URL จากข้อ 7 ต่อท้ายด้วย `?k=…` จากข้อ 6 (ติดกัน ไม่เว้นวรรค) → Update →
   เปิด **Use webhook** · **Webhook redelivery ปิดไว้**
   *(ปุ่ม Verify อาจขึ้น error หรือ timeout ได้แม้ทุกอย่างถูก — ให้ตัดสินจากข้อ 9)*
9. เชิญบอทเข้ากลุ่ม LINE ของอาจารย์ → บอทตอบ **"✅ เชื่อมกลุ่มนี้กับปฏิทินสายฟ้าแล้ว"** (ถ้าเงียบ พิมพ์อะไรก็ได้ในกลุ่ม 1 ครั้ง)
10. พิมพ์ `วันนี้` ในกลุ่ม → บอทตอบตารางวันนี้ (ไม่กินโควตา)
11. กลับที่ Apps Script เลือก **`step6_startDailyLine`** → Run — เริ่มส่งเองทุกวัน ราว 06:30 และ 18:30 (เวลาจริงคลาดได้ ±15 นาที เป็นข้อจำกัดของ Google)

ตัวอย่างข้อความรอบเช้า:

```
📅 วันนี้ พฤหัสบดี 26 พ.ย. 2569
🔴 มานิตา · 16:00–08:00 (+1) Staff on call
🟣 ชนกันต์ · 08:00–16:00 OR
🏖 ไม่อยู่
🟢 คงธัช — ลาพักร้อน (ถึง ศ. 27 พ.ย.)

🆕 เพิ่ม/แก้ไขล่าสุด
🟠 อดิศร · พฤ. 3 ธ.ค. 13:00–15:00 สอน นศพ.
```

คำที่พิมพ์ถามบอทได้ในกลุ่ม: `วันนี้` · `พรุ่งนี้` · `สัปดาห์นี้` · `ปฏิทิน`

### ความเป็นส่วนตัวของกลุ่ม LINE

เมื่อเปิด webhook LINE จะส่ง **ทุกข้อความที่พิมพ์ในกลุ่ม** มาที่สคริปต์ในบัญชี Google ของเจ้าของ สคริปต์ดูแค่ว่าเป็นคำสั่ง 4 คำข้างบนหรือไม่
**ข้อความอื่นถูกทิ้งทันที ไม่บันทึก ไม่เก็บ** ถ้าไม่สบายใจ: หลังข้อ 9 สำเร็จ ให้ปิด *Use webhook* ใน LINE — การส่งเช้า–เย็นยังทำงานปกติ
เสียแค่การพิมพ์ถามบอท

### สิ่งที่อาจเปลี่ยน

LINE ประเทศไทยประกาศว่า **ตั้งแต่ 1 ก.พ. 2570** การตอบกลับผ่าน Reply API (ที่ใช้ตอบเมื่อพิมพ์ถาม) จะต้องลงทะเบียนผ่านตัวแทนที่ LINE กำหนด
รายละเอียดยังไม่ประกาศ — ถ้าถึงตอนนั้นบอทไม่ตอบ การส่งเช้า–เย็นไม่ได้รับผลกระทบ (ใช้ Push API) และปิดการตอบได้ที่ `replyCommands: false`

| **ย้ายกลุ่ม LINE** | Run `resetLineGroup` แล้วเชิญบอทเข้ากลุ่มใหม่ |
| **แก้โค้ดแล้ว** | บันทึก แล้ว **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** (URL เดิม) — ไม่ทำ บอทจะยังใช้โค้ดเก่าตอนตอบในกลุ่ม |
| **สคริปต์ล้ม** | Google ส่งอีเมล "Summary of failures for Google Apps Script" ให้เจ้าของ พร้อมข้อความบอกสาเหตุเป็นภาษาไทย |
| **เพิ่มงานประจำใหม่** | ลงในแอปปฏิทินเป็นรายการซ้ำได้เลย · หรือเพิ่มใน `CONFIG.routine` แล้ว Run `step2_createRoutine` (ของเดิมไม่ถูกสร้างซ้ำ) |

**สำรองเจ้าของ:** ปฏิทินทั้ง 6 และสคริปต์ผูกกับบัญชี Google ของเจ้าของคนเดียว — ถ้าบัญชีนั้นถูกลบ ปฏิทินหายทั้งหมด
ควรตั้ง `deputy` (ได้สิทธิ์จัดการการแชร์) และเพิ่มอีกหนึ่งท่านเป็นผู้ดูแลบัญชี LINE ทางการ (Manager → Settings → Permissions)

## ข้อจำกัดที่ควรรู้

- สีของปฏิทินเป็นการตั้งค่ารายคนของ Google — บังคับให้ทุกเครื่องเป็นสีเดียวกันจากส่วนกลางไม่ได้
- ข้อความ LINE บอกรายการที่ **เพิ่ม/แก้** ได้ แต่ **รายการที่ถูกลบจะหายไปเฉย ๆ** ไม่มีการแจ้ง
- iPhone ที่ใช้แอปปฏิทินของเครื่องอัปเดตเป็นรอบ (ไม่ทันทีเหมือนแอป Google Calendar) — ดึงลงเพื่อรีเฟรชได้
- ทุกท่านที่มีสิทธิ์แก้ไขจะเห็นอีเมล Gmail ของกันและกันในหน้าการแชร์

## ยังไม่ได้ทดสอบบนบัญชีจริง

โค้ดผ่านชุดทดสอบ 22 ข้อที่ **จำลอง** Google Calendar และ LINE ในเครื่อง (`node --test team-calendar/google-calendar/test.mjs`)
และข้อเท็จจริงที่ใช้ออกแบบตรวจกับเอกสารทางการของ Google / LINE / Apple แล้ว แต่ยังไม่เคยรันในบัญชี Google หรือ LINE จริง
ตอนตั้งค่าครั้งแรกให้สังเกต 4 จุดนี้:

1. หลัง `step3_syncHolidays` — งานประจำหายเฉพาะวันหยุด สัปดาห์อื่นยังอยู่ครบ (สคริปต์ตรวจเองและจะหยุดถ้าผิดปกติ)
2. iPhone ที่ใช้แอปปฏิทินของเครื่อง — ปฏิทินที่แชร์ขึ้นหลังทำขั้น syncselect และลงรายการจาก iPhone แล้วเครื่องอื่นเห็น
3. บอทตอบในกลุ่มหลังตั้ง Webhook (ข้อ 9–10)
4. หลังรอบส่งแรก Run `checkLineQuota` — ตัวเลขควรเพิ่มขึ้นเท่าจำนวนคนในกลุ่ม
