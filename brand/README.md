# OR System — brand assets

App icon and logo files for **ระบบคิวห้องผ่าตัดออร์โธปิดิกส์ (OR System)** —
แผนกออร์โธปิดิกส์ (Ortho Korat) โรงพยาบาลมหาราชนครราชสีมา.

## Colors
- **Orange** `#F28E13` (tree emblem, "OR")
- **Navy** `#1E576C` ("Ortho Korat" wordmark, "System")
- App background / tile white `#FFFFFF`, UI theme `#0369A1`

## Type
- "OR System" wordmark: **Quicksand** (Bold)
- "Ortho Korat" crest: the department logo's own lettering
