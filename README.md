# ระบบคิวห้องผ่าตัดออร์โธปิดิกส์ — หน้าสาธิต

หน้าเว็บสาธิตของระบบคิวห้องผ่าตัด กลุ่มงานออร์โธปิดิกส์ โรงพยาบาลมหาราชนครราชสีมา

**เปิดที่:** https://oomkhomgt-pixel.github.io/MNRH/

เข้าสู่ระบบด้วยบัญชีทดลอง รหัสผ่านทุกบัญชีคือ `demo1234`

| ชื่อผู้ใช้ | ใช้ดูมุมมองของ |
|---|---|
| `scrub1` | พยาบาลส่งเครื่องมือ — คิว “รอฉันยืนยัน” |
| `resident1` | แพทย์ประจำบ้าน |
| `anesth1` | วิสัญญีแพทย์ |
| `supplier1` | บริษัทตัวแทนจำหน่าย — ไม่เห็นชื่อผู้ป่วยและ HN |
| `admin` | ผู้ดูแลระบบ — หน้ากำกับดูแล PDPA |

---

## ข้อมูลในหน้านี้เป็นข้อมูลสมมติทั้งหมด

- **ไม่มีข้อมูลผู้ป่วยจริงอยู่ในหน้านี้** ชื่อและรายละเอียดทุกอย่างถูกสร้างขึ้นเพื่อการสาธิต
  และ HN ทุกรายการขึ้นต้นด้วย `DEMO-`
- **หน้านี้ไม่ได้เชื่อมต่อกับระบบใดของโรงพยาบาล** ไม่มีการรับส่งข้อมูลกับเซิร์ฟเวอร์ใดทั้งสิ้น
  ทุกอย่างทำงานอยู่ในเบราว์เซอร์ของผู้เปิดเท่านั้น
- สิ่งที่แก้ไขในหน้านี้จะหายไปเมื่อรีเฟรช เพราะไม่มีการบันทึกที่ใด

จัดทำเพื่อขอความเห็นและข้อวิจารณ์จากทีมงานก่อนพิจารณานำไปใช้จริง

## For readers of this repository

This is a **demonstration page only**. It is a single self-contained HTML file: no backend,
no network requests, no analytics, no external assets. Every patient in it is fictitious.

It is published here so that colleagues can open it on their own phone without installing
anything. It is not a deployment of, and is not connected to, any hospital system.
